# JoyCircuit 3D asset provenance

The models in this directory come from official Kenney asset packs. Kenney
releases these packs under **Creative Commons Zero (CC0 1.0)**. The included
notices permit personal, educational, and commercial use; credit is appreciated
but not required.

- CC0 legal tool: https://creativecommons.org/publicdomain/zero/1.0/
- Publisher: https://kenney.nl/
- Retrieved: 2026-07-21
- Access: direct, no-login downloads from the official Kenney website

The original license notice supplied inside each downloaded archive is retained
verbatim as `LICENSE.txt` in that pack's directory.

## Project code and generated primitives

The game code, rules, UI, lighting, particles, collision shapes, procedural
terrain, and simple gameplay primitives were created for JoyCircuit. Kenney's
models are loaded as visible production art; simple Three.js geometry is used
only for mechanics such as collision floors, goal zones, projectiles, balls,
checkpoint gates, and accessibility markers.
