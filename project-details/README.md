# JoyCircuit project details

This folder contains an original design direction and build brief for a browser-games platform inspired by the fast discovery experience of Poki and CrazyGames without copying either product.

## Start here

1. Open `joycircuit-homepage-reference.png` to review the desktop visual direction.
2. Read `PROJECT-BRIEF.md` for scope, product rules, pages, and MVP criteria.
3. Copy `BUILD-PROMPT.md` into your preferred coding agent to build the platform.
4. Use `REFERENCE-IMAGE-PROMPT.md` when generating coordinated desktop, mobile, or player-page design variants.
5. Open `reference-homepage.html` in a browser if you want to inspect the responsive design source.

## Working brand

**JoyCircuit** — “Find your next favorite game.”

The name, logo, fictional games, and visual identity are concept material. Check domain, company-name, and trademark availability before a public launch.

## Important content rule

Do not scrape, hotlink, or iframe games from Poki, CrazyGames, or another portal. Publish only games you own or are explicitly licensed to distribute. Keep playable game code on an isolated, allowlisted origin with restrictive iframe permissions and Content Security Policy.
